SIRICON CORPORATE WEBSITE

Files:
- index.html: main website
- styles.css: responsive design
- script.js: language switcher, project filters and image lightbox
- assets/: 28 portfolio slides supplied for this website

Languages: Lao / Thai / English

Preview locally:
Open index.html in a browser. For best results, run a local static server.

Publish with Netlify:
1. Extract the ZIP file.
2. Open https://app.netlify.com/drop
3. Drag the extracted siricon-website folder (the folder containing index.html) onto the upload area.
4. Wait for the upload to finish and open the generated website URL.

The current package is a static public website. A secure admin/CMS requires a separate backend setup (authentication and database) before it can safely manage content.
